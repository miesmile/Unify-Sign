# assets 目录说明

本目录用于存放「云宝宝看广告」脚本（core/Yunbaobao.js）识图用的模板图片。

## ad_close.png —— 广告右上角关闭叉（必需时提供）

部分广告没有关闭控件、且返回键无效，必须手动点右上角的「叉」。脚本通过模板匹配在
**右上角区域**（宽 70%~100%，高 0~30%）内找这张图并点击。

### 存放方式（与 dingdong 脚本一致，base64 优先）

脚本识图模板的读取优先级：

1. **config_data/yunbaobao/ad_close.data**（base64 配置，同 dingdong 的 mine_base64 方式）
   —— 由 signConfig.js 注册、config_data 目录存放纯 base64 文本；
2. 兜底读取本目录的 assets/ad_close.png 文件。

更换模板图时：把新图发给豆包对话，由助手重新生成 config_data/yunbaobao/ad_close.data
（或自行用图片工具转 base64 后替换该文件内容）。

### 怎么得到模板图

方式 A（推荐）：在真机上等到广告出现那个「叉」时截图，把截图直接发给豆包对话，
由助手裁剪保存并生成配置。

方式 B（自己动手）：
1. 真机出现广告叉时用系统截图或 AutoJS 悬浮截图截一张屏；
2. 用任意图片工具把「叉」单独裁出来（越小越好，只保留叉本身，背景尽量少）；
3. 命名为 ad_close.png 放到本目录（PC 端路径：C:\y30040589\Unify-Sign\assets\ad_close.png）；
4. 把整个工程同步到手机 AutoJS 后，脚本会自动读取。

### 注意
- 模板图尺寸建议 20~80 像素，只包含叉，不要包含大片背景；
- 如果不同广告的叉样式差别很大，可以后续扩展多个模板（ad_close2.png 等），
  代码里再按需加载。
